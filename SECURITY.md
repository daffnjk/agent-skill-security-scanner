# Security policy

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities that could put users at risk. Use GitHub's private vulnerability reporting flow:

https://github.com/daffnjk/agent-skill-security-scanner/security/advisories/new

Include affected versions, reproduction steps, impact, and any suggested mitigation. Do not include real secrets or harmful payloads.

## Scope

Security reports about scanner crashes, unsafe file handling, path traversal, denial of service, unintended command execution, or incorrect trust-boundary behavior are welcome. Detection misses and false positives can be reported as ordinary issues when the sample is safe to publish.
