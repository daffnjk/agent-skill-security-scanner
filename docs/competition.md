# 赛事背景与成绩声明

## 赛事信息

- 赛事：首届火山引擎 AI 安全攻防挑战赛（2026）
- 赛道：赛道 B（蓝队检测挑战）
- 提交形式：Docker 化 Agent Skill 扫描检测引擎
- 输入：`/data/skills/{skill_id}/`
- 输出：`/output/results.jsonl`

赛道使用隐藏的黑、白、灰样本评测检测引擎。公开规则中，检测质量占 55%，性能占 10%，OWASP AST 主分类可解释性占 20%，运行稳健性占 15%。公开赛后资料称，蓝队共有 617 支队伍参与，累计提交约 7,200 个引擎文件，赛道最高综合分为 8.74。

## 本项目公开成绩

最初的比赛版本在比赛期间曾进入**公开阶段榜单 20 多名**。

该成绩描述的是早期竞赛原型。当前开源仓库基于后续的 **v38 / recall micro-loop 115** 工程版本，包含赛后新增的规则、特异性、格式兼容和稳健性改进；本项目不将其表述为获得了相同或更高名次的官方复评版本。

目前仓库材料中没有可核验的个人精确分数记录，因此不填写猜测值。后续只有在取得公开榜单截图或其他可核验记录后，才应补充精确分数、截图日期和榜单阶段。

## 独立性与披露边界

本仓库是参赛者独立维护的非官方开源项目，不代表火山引擎或赛事组委会立场，也不暗示官方背书。

仓库不包含赛事隐藏样本、标准答案、内部评测数据、未公开接口、平台凭据或其他未公开赛事材料。
