# 赛事背景与最终成绩声明

## 赛事信息

- 赛事：首届火山引擎 AI 安全攻防挑战赛（2026）
- 赛道：赛道 B（蓝队检测挑战）
- 提交形式：Docker 化 Agent Skill 扫描检测引擎
- 输入：`/data/skills/{skill_id}/`
- 输出：`/output/results.jsonl`

赛道使用隐藏的黑、白、灰样本评测检测引擎。公开规则中，检测质量占 55%，性能占 10%，OWASP AST 主分类可解释性占 20%，运行稳健性占 15%。

## 成绩解读

- **性能 1.00 / 1.00**：最终版本在性能维度获得满分，体现了纯 Go、零第三方运行依赖、离线确定性扫描和有界资源设计的工程优势。
- **检测质量 4.34 / 5.50**：这是总分的主要贡献项，与项目围绕 F₂ 进行高信号召回增强的路线一致。
- **可解释性 1.10 / 2.00**：项目能够输出主 AST 类别和证据，但精确主分类仍有继续提升空间。
- **运行稳健性 0.83 / 1.50**：最终版本具备异常兜底、资源限制和原子结果写入，但正式评测结果表明该维度仍是后续优化重点。

## 版本真实性

仓库中的核心检测器、Dockerfile、输出协议、规则演进文档和 v38 recall micro-rules 对应最终参赛版本。README 中披露的 `7.27 / 10` 和 `20+` 排名只对应该最终提交版本，不延伸代表未来分支、未发布规则或第三方修改版本的成绩。

本地合成基准、自测结果和后续社区测试不得与赛事官方分值混用。若项目继续开发，新的版本应明确标注为“基于 v38 的后续版本”，并避免暗示已经获得赛事重新评测。
