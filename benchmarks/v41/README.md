## 完整性与限制

- 所有 56,004 个输入都写入了分类结果；7 个样本被 fail-closed 收集器标记为扫描不完整：AgentTrap 3 个、MalSkillBench 1 个、SkillGuard v2 2 个、SkillTrustBench 1 个。
- `completed_with_scan_warnings` 表示分类行存在，但检测器返回退出码 3；GitHub Action 会阻断这类运行，不能把它当作完整通过。
- `metrics.csv` 同时保存严格与筛查口径，并在 v38 字段之后追加误报率、准确率和平衡准确率。
- 数据集可能重叠、标签策略不同，因此不把各数据集混合成一个全局分数。宏平均只能作为版本回归诊断，不能解释为真实部署效果。
- 规则源码不包含数据集名称、样本 ID 或固定样本白名单；新增规则由恶意样例和良性反例成对测试。

数据集修订见 [`source_revisions.tsv`](source_revisions.tsv)，检测器和产物摘要见 [`manifest.json`](manifest.json)。原始恶意样本、逐样本预测和材料化目录不提交到本仓库。
